Every identified edge case and its defined system behavior, for spec review.
Conflict
Same field, multiple sources
System shows both values inline, highlights the discrepancy, defaults to highest-confidence source, prompts user to confirm. Conflict is recorded in extraction_meta.
Missing
Required field not found
Field rendered as empty with red border. User must manually enter before confirmation is allowed. System blocks "Confirm" until all required fields are filled.
Ambiguous
Date format ambiguity (01/02/03)
System uses locale context and email header date for disambiguation. If still ambiguous, flags field as medium confidence and requests user confirmation.
Duplicate
PO number already in system
System checks existing orders on intent detection. If duplicate PO found, shows side-by-side diff before extraction. User must explicitly choose: update, ignore, or create new.
Low Quality
Corrupted or low-res image/PDF
OCR confidence below 60% triggers a source-level warning. Fields from that source shown with "Low" badge. User prompted to re-upload cleaner file or enter manually.
Blocked
Password-protected PDF
System cannot extract. User is shown a prompt to forward the unlocked file or enter order data manually. Attachment noted as "locked" in audit log.
Multi-file
Multiple attachments, same order
System merges extracted fields, using source priority: PDF structured > Excel > Image OCR > email body. Source shown per field. Conflicts surfaced individually.
Multi-order
Single email, multiple POs
System detects multiple PO numbers and splits into separate extraction sessions. User sees "2 orders detected" banner and reviews each independently.
Non-order
Intent below threshold (<60%)
Email routed to "Unclassified" queue. No extraction attempted. User manually assigns intent or discards. All signals logged for model feedback.
UOM mismatch
Mixed units in same order
Line items with differing UOM (EA vs CS vs PL) flagged individually. System suggests standard conversion if mapping exists in master data. User confirms or overrides.
Currency
Ambiguous or missing currency
System infers from customer master (default billing currency). If no match, flags as missing. All prices stored with explicit currency in JSON output regardless.
Partial
Header found, no line items
System extracts what it can and flags missing sections. User can add line items manually. Partial extractions saved as drafts, not sent to ERP until complete.
